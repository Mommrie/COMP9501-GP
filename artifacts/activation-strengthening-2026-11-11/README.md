Exploratory extension after v3 final inspection. The allocated L4 is used for all new FP32 controls; historical A100 baseline/timing stages stay distinct.

- summary.json and CSVs: independently audited metrics and paired comparisons.
- activation-controls.png, routing-controls.png, routing-impact.png: study figures.

- seed*-*: complete histories, locked choices, split IDs, shuffled permutations and prediction arrays.
- plan, sources and preflight: exact execution evidence.
- manifest.json: SHA256 of all other evidence files.

Oracle uses final GT and is an accuracy ceiling, not a deployment method. Source recognition is not expert utility.
