All ten figures have PNG and SVG versions with matching stems:

| Stem | Meaning |
|---|---|
| `01-projection-pipeline` | Shapes and the alternating-update workflow |
| `02-reconstruction-gallery` | Fixed MNIST examples; CSA/PCA at matched latent sizes |
| `03-basis-images` | Separable outer-product bases versus unrestricted PCA bases |
| `04-equal-latent-results` | Three-subset accuracy/MSE versus latent size |
| `05-storage-budget-results` | Accuracy/MSE when PCA must fit within each CSA storage limit |
| `06-storage-accounting` | Basis scalars versus total collection scalars |
| `07-objective-convergence` | Normalized captured training energy after each mode update |
| `08-initialization-sensitivity` | Covariance plus eight random starts on one fixed subset |
| `09-three-mode-reconstruction` | Known-model synthetic held-out 3D reconstruction check |
| `10-original-paper-table-IV` | Redrawn author-reported Gabor MNIST results, not our experiment |

`results.json` contains the plan, environment, data/source hashes, native sample IDs,
all 21 grid points, convergence traces, archival parity, restarts and synthetic checks.
`results.csv` contains 63 rows (21 configurations x 3 comparison entries), including
per-method dimensions and storage. `results-table.md` gives all aggregate mean +/- SD.
`SHA256.json` covers generated outputs, excluding itself and this hand-written README.

Generated by [prepare_presentation.py](../../code/prepare_presentation.py), with
[plan.json](../plan.json). See [experiment interpretation](../EXPERIMENTS.zh-CN.md)
before reusing numbers. SVG text remains editable; its appearance depends on the
viewer's installed fonts. PNG supplies a stable raster alternative.
