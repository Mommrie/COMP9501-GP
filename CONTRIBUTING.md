# Working together

Use your own account for commits. For a larger change, a branch and a short PR can make discussion easier; small fixes can follow whatever the group agrees.

Please include enough context to run changed code: the command, config and any useful result or limitation.

If runtime code or configs change, refresh the embedded Colab notebook so it runs the intended version. The repository checker is an optional convenience, not a team approval process.

Keep credentials and large data/model files out of code commits. Experiment outputs are easier to compare when saved under distinct run names.
